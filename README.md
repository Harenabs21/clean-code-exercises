# CLEAN CODE EXERCISES

This repository contains the first exercise of PROG5 course about clean code.

## RUN THE SCRIPT

In order to run the program, you have to do the following commands:

- First of all, if you didn't have the `typescript` package yet in your system, you have to install it with you package manager, for example with npm:

```bash
npm install -g typescript
```

- After that, compile the `main.ts` file:

```bash
tsc main.ts
```

- Finally, run the compiled file:

```bash
node main.js
```
